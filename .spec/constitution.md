# RANA LEATHER'S - Constitution

## Mission
To provide premium, handcrafted leather products with an exceptional online shopping experience, combining traditional Pakistani craftsmanship with modern technology.

## Core Principles

1. **Quality First**: Every product showcased meets premium leather standards using full-grain and vegetable-tanned leathers
2. **Customer Trust**: Transparent pricing, clear product descriptions, and honest representation of materials
3. **Performance Excellence**: Fast loading times, smooth navigation, and responsive design across all devices
4. **Mobile-First Design**: Seamless experience on smartphones, tablets, and desktops
5. **Accessibility**: WCAG 2.1 compliant, usable by everyone regardless of ability

## Technical Standards

- **TypeScript**: Strict mode enabled, no `any` types without justification
- **Next.js 14**: App Router, Server Components where possible, client components for interactivity
- **Tailwind CSS**: Utility-first styling, consistent design tokens using custom colors
- **Component Architecture**: Reusable, testable components with single responsibility
- **Error Handling**: Graceful fallbacks, user-friendly error messages, and logging

## Design Guidelines

- **Color Palette**:
  - Primary: #8B3A1A (Rich Cognac)
  - Secondary: #1A0F0A (Deep Espresso)
  - Accent: #D4AF37 (Gold)
  - Background: #F5EFE6 (Cream)
  - Text: #2C2C2C (Charcoal)
  
- **Typography**:
  - Headings: Playfair Display (serif, elegant, premium feel)
  - Body: Inter (sans-serif, readable, modern)

- **Spacing**: 8px grid system for consistent spacing
- **Animations**: Subtle, purposeful transitions (0.3s-0.5s duration)

## Development Rules

1. All commits must follow conventional commits format (feat/fix/docs/style/refactor)
2. Each feature branch must have a corresponding task file in `.spec/tasks/`
3. Mobile testing before desktop deployment
4. No console logs in production
5. Environment variables for all sensitive data
6. Code review required for all pull requests

## Brand Voice
- Professional yet warm
- Educational about leather craftsmanship
- Proud of Pakistani heritage
- Transparent about materials and pricing
